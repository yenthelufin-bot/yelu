Je krijgt een gerangschikte lijst terug met scores, kleurpalet en lichtadvies. Bewaar je favorieten en exporteer ze naar Google My Maps.

    Google-sleutel

    Hoe maak ik een sleutel aan? (± 10 minuten)
    1. Ga naar console.cloud.google.com en log in met je Google-account.
    2. Klik bovenaan op de projectkiezer → Nieuw project, noem het Location Scout en kies het daarna.
    3. Menu ☰ → Facturering: koppel een factureringsaccount. Google vraagt een bankkaart, maar Location Scout blijft onder het gratis gebruik.
    4. Menu ☰ → API's en services → Bibliotheek: zoek en schakel deze vier in:
      • Geocoding API
      • Places API (New)
      • Street View Static API
      • Maps Embed API
    5. API's en services → Inloggegevens → + Inloggegevens maken → API-sleutel. Kopieer de sleutel.
    6. Aangeraden: bewerk de sleutel en beperk hem onder API-beperkingen tot die vier API's. Zet onder Facturering → Budgetten een budgetmelding van € 1.
    2

    Gemini-sleutel (beoordeelt de foto's)

    Hoe maak ik een gratis Gemini-sleutel aan? (± 2 minuten)
    1. Ga naar aistudio.google.com/apikey en log in met je Google-account.
    2. Klik op Create API key (API-sleutel maken).
    3. Belangrijk: kies daarbij een nieuw project, niet het project van stap 1. Koppel aan dat nieuwe project géén facturatie: zonder facturatie blijft Gemini op de gratis versie en kan het je nooit iets kosten.
    4. Kopieer de sleutel en plak hem hieronder.

    De gratis versie heeft een limiet per minuut en per dag. Location Scout wacht vanzelf als Google dat vraagt en stopt netjes bij de daglimiet. In AI Studio zie je bij Usage je actuele limieten.

    +

    Optioneel: ook zoeken vanuit de Claude-app

    Niet nodig om in de browser te zoeken. Hiermee kun je ook in de Claude desktop-app vragen om locaties te zoeken; Claude bekijkt de foto's dan binnen je abonnement. Na het koppelen moet je de Claude-app volledig afsluiten en opnieuw openen.
